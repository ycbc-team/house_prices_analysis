# raw/ — 原始来源文件

存放**未经加工的原始来源材料**，包括但不限于：

- 政府公开数据：统计局统计公报、六普/七普公报、规划和自然资源局土地出让公告、住建局网签数据的截图或导出文件
- 平台数据：贝壳/链家/58 同城等中介平台的成交数据导出、页面存档
- 研究报告、媒体报道的原始页面存档

命名建议：`<来源>_<指标>_<时间范围>.<ext>`，例如 `beike_gz_district_price_202610.csv`、`gz_stats_bulletin_2025.pdf`。

> 原始文件通常包含非结构化或半结构化内容，经 `scripts/` 中的转录/解析流程处理后写入 `parsed/`。
