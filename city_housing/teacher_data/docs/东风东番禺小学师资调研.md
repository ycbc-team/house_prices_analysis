## 二、核心发现（基于1361条公示记录的实证分析）

### 1. 优才计划不招小学教师

已分析全部5批优才计划公示名单（共179人），招聘单位全部为中学：

| 招聘单位 | 人数 |
|---|---|
| 广东仲元中学 | 40 |
| 广东番禺中学 | 29 |
| 禺山高级中学 | 25 |
| 象贤中学 | 15 |
| 番雅实验学校/广雅实验学校 | 20 |
| 其他中学 | 50+ |

**结论：优才计划是中学教师专项招聘，小学教师不在此列。**

### 2. 统考名单中暂未出现东风东番禺小学

已分析2025年统考第一批、第二批、2026年统考第一批名单，均未找到"东风东教育集团番禺小学"。

### 3. 教师队伍现状推断

学校2025年9月才开学（仅招6个班），当前教师队伍主要构成为：

| 来源 | 说明 |
|---|---|
| **本部派驻** | 管理团队+骨干教师来自东风东路小学本部（校长就是原本部副校长） |
| **临聘教师** | 智联招聘挂出岗位：本科，8000-10000元/月，招40人 |
| **后续编制招聘** | 学校刚开学，编制内教师预计在2026-2027年逐步通过统考进入公示名单 |

## 三、优才计划学历门槛（已验证）

从实际名单中确认：
- **优才计划录用人员全部为硕士研究生**
- 毕业院校包括：北京师范大学、华南师范大学、北京邮电大学、湖南师范大学等
- 岗位全部为中学（初中/高中）
